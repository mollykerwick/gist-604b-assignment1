## Understanding Git Workflow
Explain in 2–3 sentences the difference between:
- Local workspace (Codespace)
- Remote repository (GitHub.com)
- Answer: A local workspace is where I am working on editing my code. A remote repository is where I store updates I make and document those changes using commit messages. I can pull from and push to the remote repository via multiple different local workspaces, making it easy for a group of people to collaboratively work on the same project.
